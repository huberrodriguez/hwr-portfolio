# Portafolio profesional — Huber Wilfredo Rodríguez

Sitio estático en HTML, CSS y JavaScript, con cinco demostraciones interactivas. No requiere base de datos, servidor propio ni suscripción.

## Estructura
- `index.html`: página principal del portafolio.
- `styles.css` y `script.js`: estilos y comportamiento del sitio principal.
- `proyectos/erp-talento-humano.html`: demostración de un módulo ERP de talento humano con búsqueda y filtros.
- `proyectos/bi-ventas.html`: dashboard BI de ventas con selector de periodos.
- `proyectos/etl-datos.html`: demostración ETL con limpieza de datos y descarga CSV.
- `proyectos/consultas-plsql.html`: laboratorio ilustrativo de consultas SQL, procedimientos y funciones PL/SQL.
- `proyectos/python-analisis.html`: análisis interactivo de ventas de muestra; incluye `analisis_ventas.py` y `ventas_demo.csv` para ejecutar con Python 3.
- `proyectos/demo.css`: estilos compartidos por las demostraciones.

## Verlo localmente
1. Descomprime el ZIP.
2. Abre `index.html` en el navegador.
3. En la sección Proyectos, pulsa **Explorar proyecto** en cualquiera de las tarjetas.

## Publicarlo gratis con GitHub Pages
1. Ingresa a https://github.com e inicia sesión.
2. Crea un repositorio público llamado `huberrodriguez.github.io` (si ese nombre está disponible para tu cuenta).
3. Sube todo el contenido de esta carpeta, incluida la carpeta `proyectos`.
4. En el repositorio, entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**, luego `main` y `/(root)`, y guarda.
6. Cuando GitHub termine la publicación, la página quedará en `https://huberrodriguez.github.io`.

Si el nombre exacto del repositorio no está disponible o no coincide con tu usuario, puedes usar otro nombre y activar Pages; la URL tendrá el formato `https://huberrodriguez.github.io/nombre-del-repositorio/`.

## Importante antes de publicar
- Revisa los cargos, periodos y descripciones laborales para confirmar que reflejen exactamente tu experiencia.
- No se publica la sección de formación académica, según tu solicitud.
- Las cinco demos son proyectos demostrativos construidos para el portafolio, con datos ficticios. No son el SIATH ni representan sistemas de empleadores o clientes.
- La demostración SQL/PLSQL no se conecta a Oracle: presenta código y resultados ilustrativos.
- La vista interactiva de Python corre en el navegador; también se entrega un script Python real y un CSV de muestra para ejecutarlo localmente.
- No se incluye correo ni teléfono porque aún no han sido suministrados.
